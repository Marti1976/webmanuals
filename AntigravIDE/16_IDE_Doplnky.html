Doplňky (Extensions)

Jak instalovat rozšíření v programu i externě, kde je hledat, a TOP 10 doplňků které mají smysl — včetně české jazykové sady na prvním místě.

🧩 Extensions 📦 OpenVSX 🛒 Marketplace
// sekce 01

Co jsou doplňky v Antigravity IDE

Antigravity IDE je fork VS Code — takže doplňky fungují úplně stejně jako ve VS Code. Nainstalovaný doplněk přidá nové funkce, zvýrazňování, formátování, nebo celý UI panel.

ℹ️
Důležitý rozdíl: OpenVSX vs VS Code Marketplace

Antigravity IDE ve výchozím nastavení používá OpenVSX registry (open-vsx.org), ne Microsoft VS Code Marketplace. To znamená, že některé oblíbené doplňky ve vyhledávání nenajdeš — existují jen na VS Code Marketplace. Řešení je buď ruční instalace (.vsix), nebo přepnutí marketplace (viz sekce 04).

Co Antigravity IDE má již zabudované (nepotřebuješ doplněk)

  • Git integrace — history, blame, diff jsou nativní, nepotřebuješ GitLens pro základní použití
  • AI asistent — Gemini 3 je zabudovaný, nepotřebuješ Copilot ani jiný AI doplněk
  • Firebase integrace — přímé propojení bez bridge pluginu
  • Multi-root workspace — správa více projektů nativně
  • Browser testing — Chrome extension je zabudovaná součást, ne plugin

Přesto existuje řada doplňků které práci výrazně zlepší — zejména jazyková podpora, formátování kódu a vizuální vylepšení.

// sekce 02

Instalace v programu

Nejjednodušší způsob — přímo z Antigravity IDE přes Extensions panel.

01
Otevři Extensions panel
Klávesová zkratka Ctrl+Shift+X (Windows/Linux) nebo Cmd+Shift+X (Mac). Nebo klikni na ikonu čtverce v levém postranním panelu.
02
Vyhledej doplněk
Do vyhledávacího pole napiš název nebo ID doplňku (např. ms-ceintl.vscode-language-pack-cs). Výsledky jsou z OpenVSX registry.
03
Klikni Install
Klikni na modré tlačítko Install u vybraného doplňku. Antigravity IDE ho stáhne a nainstaluje automaticky — bez restartu.
04
Aktivace (pokud je potřeba)
Některé doplňky (jako jazykové balíčky) zobrazí notifikaci "Restart to activate" nebo "Set as display language". Klikni na nabízenou akci.
✓
Správa nainstalovaných doplňků

V Extensions panelu přepni na záložku "Installed" (ikona filtru nebo text "Installed") abys viděl co máš nainstalováno. Každý doplněk lze deaktivovat (Disable) nebo odebrat (Uninstall) bez ztráty dat projektu.

// sekce 03

Instalace externě (.vsix)

Pokud doplněk není na OpenVSX, stáhneš ho jako soubor .vsix a nainstaluješ ručně. Jsou dvě cesty.

Způsob A — přes UI (jednodušší)

01
Stáhni .vsix soubor
Jdi na marketplace.visualstudio.com, najdi doplněk, klikni na záložku "Version History" a stáhni poslední .vsix soubor.
02
Extensions panel → tři tečky (···)
V Extensions panelu klikni na ikonu ··· (nebo ozubené kolečko) v pravém horním rohu panelu. Vyber "Install from VSIX..."
03
Vyber stažený soubor
Najdi a otevři stažený .vsix soubor. Antigravity IDE ho nainstaluje okamžitě.

Způsob B — přes příkazový řádek (přesnější)

Otevři terminál (mimo Antigravity IDE) a spusť příkaz pro tvůj systém:

# macOS
/Applications/Antigravity IDE.app/Contents/Resources/app/bin/antigravity --install-extension nazev-doplnku-1.0.0.vsix

# Windows (PowerShell)
& "C:\Users\[uzivatel]\AppData\Local\Programs\Antigravity IDE\resources\app\bin\antigravity.cmd" --install-extension nazev-doplnku-1.0.0.vsix

# Linux
/usr/share/antigravity/bin/antigravity --install-extension nazev-doplnku-1.0.0.vsix
⚠️
Nepoužívej příkaz code ani cursor

Příkaz code --install-extension nebo cursor --install-extension nainstaluje doplněk do VS Code / Cursor, ne do Antigravity IDE. Každý editor má vlastní registry. Musíš použít příkaz antigravity.

// sekce 04

Přepnutí na VS Code Marketplace

Chceš-li mít přímý přístup k celému VS Code ekosystému bez ruční instalace, přepni Antigravity IDE na Microsoft marketplace. Pak vyhledávání funguje stejně jako ve VS Code.

⚠️
Pozor — Microsoft to technicky nedovoluje

Microsoft licenčně omezuje přístup k VS Code Marketplace jen pro VS Code. Funguje to technicky, ale narušuješ licenční podmínky. Pro bezpečnou cestu používej OpenVSX nebo ruční .vsix instalaci.

Postup (na vlastní riziko)

01
Otevři Nastavení
Ctrl+, → vlevo vyhledej "extensionsGallery" nebo jdi do Settings → Antigravity IDE Settings → Editor
02
Uprav marketplace URLs
Nahraď hodnoty za Microsoft URLs:
serviceUrl → https://marketplace.visualstudio.com/_apis/public/gallery
itemUrl → https://marketplace.visualstudio.com/items
03
Restart Antigravity IDE
Po restartu bude Extensions panel prohledávat VS Code Marketplace. Instalace a aktualizace fungují standardně.

// sekce 06

TOP 10 doplňků

Výběr vychází z praktického použití. Na prvním místě je čeština — záměrně, protože to první co chceš udělat je přepnout UI do svého jazyka.

# 01 — Doporučujeme začít tímto
Czech Language Pack
ms-ceintl.vscode-language-pack-cs
Přeloží celé UI Antigravity IDE do češtiny — menu, tlačítka, dialogy, nastavení. Po instalaci tě Antigravity IDE vyzve ke změně jazyka. Jediný klik a máš celý program v češtině. Nezasahuje do funkčnosti, pouze přeloží texty.
Jazyk Doporučeno
📦 Dostupné na: OpenVSX (přímá instalace v programu)
# 02
Prettier – Code Formatter
esbenp.prettier-vscode
Automaticky formátuje kód při uložení souboru. Podporuje JavaScript, TypeScript, CSS, HTML, JSON, Markdown a další. Zajistí že kód agenta i tvůj vlastní bude vždy konzistentně naformátovaný — žádné hádky o mezerách a středníky.
Formátování Doporučeno
📦 Dostupné na: OpenVSX
# 03
ESLint
dbaeumer.vscode-eslint
Linting pro JavaScript a TypeScript — podtrhuje chyby a špatné vzory přímo v editoru ještě před spuštěním. Pracuje spolu s agentem: agent vidí ESLint varování a může je opravit ještě před commitem. Nezbytné pro TypeScript projekty.
Linting TypeScript
📦 Dostupné na: OpenVSX
# 04
Error Lens
usernamehw.errorlens
Zobrazuje chybové hlášky a varování přímo na řádku kde nastaly — ne jen jako ikona na konci řádku. Výrazně zrychluje debugging: okamžitě vidíš co a kde je špatně, aniž bys přejížděl myší nebo otevíral Problems panel.
Debugging Velký dopad
📦 Dostupné na: OpenVSX
# 05
GitLens — Git supercharged
eamodio.gitlens
Rozšiřuje nativní Git integraci Antigravity IDE o inline blame (kdo napsal řádek a kdy), detailní historii souboru, vizualizaci větví a porovnání commitů. Antigravity IDE má základní Git zabudovaný — GitLens přidá hloubku pro pokročilou práci s historií.
Git Historie
📦 Dostupné na: OpenVSX
# 06
Tailwind CSS IntelliSense
bradlc.vscode-tailwindcss
Autocomplete pro Tailwind CSS třídy přímo při psaní v HTML, JSX, TSX. Zobrazuje náhled barev, varuje před neplatnými třídami a zobrazuje generované CSS při hoveru. Pokud používáš Tailwind (a v projektech s agentem ho pravděpodobně budeš), je tohle nutnost.
CSS Tailwind
📦 Dostupné na: OpenVSX
# 07
Thunder Client
rangav.vscode-thunder-client
Lehký REST API klient přímo v editoru — alternativa k Postman. Testuj API endpointy bez opuštění Antigravity IDE. Výhodné pokud agent vytvoří backend: hned ho otestuješ v jednom okně. Podporuje kolekce requestů, environment proměnné a spouštění v rámci testů.
API Testing
📦 Dostupné na: OpenVSX
# 08
Auto Rename Tag
formulahendry.auto-rename-tag
Při přejmenování HTML/JSX opening tagu automaticky přejmenuje i closing tag. Malá věc, ale šetří obrovské množství zbytečných úprav při práci s HTML a JSX komponentami. Funguje spolehlivě a bez konfigurace.
HTML JSX
📦 Dostupné na: OpenVSX
# 09
Material Icon Theme
PKief.material-icon-theme
Nahrazuje výchozí ikony souborů a složek v Explorer panelu barevnými Material Design ikonami. Každý typ souboru (.ts, .json, .md, .env…) má vlastní rozlišitelnou ikonu. Velký projekt se pak orientuje rychleji — na první pohled víš co je co.
UI Ikony
📦 Dostupné na: OpenVSX
# 10
GitHub Theme
GitHub.github-vscode-theme
Populární barevné téma inspirované GitHub rozhraním — světlé i tmavé varianty. Pokud přicházíš z VS Code a chceš si zachovat vizuální zvyk, nebo prostě chceš čisté profesionální téma, je GitHub Dark Default nebo GitHub Dark Dimmed skvělá volba.
Téma Vzhled
📦 Stáhnout jako .vsix: marketplace.visualstudio.com
✓
Tip: Méně je více

Antigravity IDE má hodně zabudovaného. Nestříkej doplňky po hrstech jako ve VS Code — každý doplněk navíc může zpomalit editor nebo kolidovat s agentem. Začni s češtinou + Prettier + ESLint a přidávej jen co reálně potřebuješ.
