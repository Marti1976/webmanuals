Instalace

Všechny způsoby jak spustit Claude Code — native installer pro CLI, Desktop aplikace pro macOS a Windows, IDE pluginy pro VS Code a JetBrains, a webové rozhraní bez instalace.

Přehled rozhraní — co si vybrat

RozhraníPlatformyFunkceIdeální pro
CLI (terminál)macOS · Linux · WindowsPlnéVývojáři znalí terminálu, scripting, CI/CD
Desktop AppmacOS · WindowsPlné + GUIVizuální diff, paralelní sessions, mobil sync
VS Code pluginmacOS · Linux · WindowsTéměř plnéVS Code, Cursor, Windsurf uživatelé
JetBrains pluginmacOS · Linux · WindowsTéměř plnéIntelliJ, WebStorm, PyCharm, GoLand
Web rozhraníProhlížečOmezenéRychlý start, jiné zařízení, GitHub projekty
Doporučení pro začátečníky

Začněte s Desktop App pokud jste na macOS nebo Windows — má grafické rozhraní a nemusíte řešit nastavení terminálu. Pokud jste pokročilý uživatel nebo pracujete na Linux, CLI je výkonnější a flexibilnější.

CLI — native installer (doporučená metoda)

Od roku 2026 je nativní instalátor jediná doporučená cesta pro CLI. Nevyžaduje Node.js, automaticky se aktualizuje na pozadí a je k dispozici pro všechny platformy.

macOS a Linux — jeden příkaz

Terminal · bash / zsh
# Instalace přes native installer
curl -fsSL https://claude.ai/install.sh | bash

# Instalace přes Homebrew (macOS)
brew install --cask claude-code

# Homebrew neaktualizuje automaticky — spouštějte periodicky:
brew upgrade claude-code

# Ověření instalace
claude --version
→ claude 1.x.x (nebo aktuální verze)

Po instalaci se příkaz claude přidá do PATH. Pokud shell hlásí "command not found", spusťte source ~/.zshrc (nebo ~/.bashrc pro bash) — tímto refreshnete PATH bez restartu terminálu.

Windows — instalace

PowerShell (jako administrátor)
# Varianta 1: Native PowerShell instalátor (doporučeno)
irm https://claude.ai/install.ps1 | iex

# Varianta 2: WinGet
winget install Anthropic.ClaudeCode

# WinGet neaktualizuje automaticky:
winget upgrade Anthropic.ClaudeCode

# Varianta 3: Stáhněte .msi instalátor z
# https://claude.com/download

Git Bash vs PowerShell: Claude Code interně vždy používá Git Bash pro spouštění příkazů, i když ho spustíte z PowerShell. Nainstalujte Git for Windows z git-scm.com — při instalaci vyberte "Add to PATH". Bez Git Bash bash příkazy v Claude Code selžou.

WSL2: Pokud pracujete s Linux projekty z Windows, spouštějte Claude Code přímo z WSL2 terminálu (Ubuntu) — funguje identicky jako na Linux a Git Bash nepotřebujete.

Linux — balíčkové systémy

Různé distribuce
# Debian / Ubuntu
sudo apt install claude-code

# Fedora / RHEL / CentOS
sudo dnf install claude-code

# Arch Linux (AUR)
yay -S claude-code

# Alpine Linux
apk add claude-code

# Nebo universal native installer
curl -fsSL https://claude.ai/install.sh | bash
npm instalace — zastaralé

Instalace přes npm install -g @anthropic-ai/claude-code je od roku 2026 deprecated. Pokud ji máte, odinstalujte ji a přejděte na native installer. Native installer nevyžaduje Node.js a aktualizuje se automaticky.

Desktop aplikace (vydána duben 2026)

Desktop App není jen wrapper nad CLI — je to plnohodnotné vývojové prostředí optimalizované pro agentic práci. Klíčová funkce jsou paralelní sessions: každá session dostane vlastní izolovanou kopii projektu přes Git worktrees. Můžete spustit refaktoring frontendu a backendu zároveň, sledovat oba živě a merge výsledky standardním PR workflow.

  • Monaco editor (stejný základ jako VS Code) — vizuální diff před zápisem, zvýrazňování syntaxe
  • Integrovaný terminál — spouštění testů přímo v aplikaci ve working directory session
  • Vzdálené ovládání z mobilu — spouštění a monitoring desktop sessions z Claude mobilní aplikace
  • Přehled všech sessions — jedna karta = jedna session, vidíte stav, spotřebu, progress

# Linux: NENÍ dostupné, použijte CLI

# Po instalaci se Desktop App a CLI sdílí autentizaci —

IDE rozšíření

VS Code (+ Cursor, Windsurf)

  • Otevřete VS Code → Extensions (Ctrl+Shift+X) → hledejte Claude Code
  • Instalujte rozšíření od Anthropic (ověřte vydavatele)
  • Po instalaci se logo Claude objeví v pravém horním rohu editoru a v activity baru
  • Přihlaste se přes claude.com nebo API klíč — sdílí session s CLI
  • Funguje stejně v Cursor a Windsurf (oba jsou forky VS Code)

JetBrains (IntelliJ, WebStorm, PyCharm, GoLand…)

  • Otevřete Settings → Plugins → Marketplace → hledejte Claude Code
  • Instalujte a restartujte IDE
  • Plugin přidá panel Claude Code do pravého sidebaru
  • Stejná autentizace jako CLI — API klíč nebo předplatné

Webové rozhraní

Claude Code lze spustit přímo z prohlížeče na claude.ai. Pro práci s kódem v GitHub repozitáři autorizujte Claude App v GitHub Settings → Applications.

Omezení webového rozhraní: pomalejší než CLI, omezené bash příkazy, nelze nainstalovat vlastní MCP servery. Vhodné pro: rychlé jednorázové dotazy ke kódu, práci z jiného zařízení (tablet, školní počítač) nebo onboarding nových členů týmu bez instalace.

Autentizace — přihlášení po instalaci

Existují dva způsoby autentizace a každý se hodí pro jiný platební model:

Způsoby přihlášení
══ VARIANTA 1: Předplatné (Pro/Max) ══
# Přihlaste se přes browser — otevře claude.com/login
claude auth login
# Přihlaste se Claude účtem v prohlížeči
# Token se automaticky uloží → hotovo

══ VARIANTA 2: API klíč (pay-per-token) ══
# Získejte klíč na console.anthropic.com → API Keys
export ANTHROPIC_API_KEY="sk-ant-api03-..."

# Pro trvalé uložení přidejte do ~/.zshrc nebo ~/.bashrc:
echo 'export ANTHROPIC_API_KEY="sk-ant-..."' >> ~/.zshrc
source ~/.zshrc

══ VARIANTA 3: Login loop nefunguje? ══
claude auth login --print-redirect-url
# Zkopírujte URL s tokenem a vložte ručně
Kde získat API klíč

Přihlaste se na console.anthropic.com → API Keys → Create new key. Nový účet dostane $5 v kreditech zdarma pro vyzkoušení. API klíče začínají prefixem sk-ant-.

Ověření a první spuštění

Rychlé ověření
# Ověření verze
claude --version
→ claude 1.x.x  ✓

# Ověření autentizace
claude -p "Ahoj, funguje to?"
→ Claude odpoví  ✓

# První skutečné spuštění v projektu
cd ~/muj-projekt
claude
→ Claude načte strukturu, přečte CLAUDE.md (pokud existuje)
→ Zadejte první úkol přirozeným jazykem
