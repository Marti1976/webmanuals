Limity & Efektivita

Jak fungují limity tokenů, jak se spalují, a co dělat aby stejný tarif zvládl dvakrát až třikrát více práce. Včetně kompletního Master Promptu pro audit vaší efektivnosti a návyků kterými si zachováte cache.

Jak fungují limity tokenů — základní princip

Claude Code nemá paměť. Každá zpráva, kterou pošlete v session, znovu odešle celou konverzaci od samého začátku. Pokud vaše session má 50 předchozích zpráv, všechny se opakují. Jeden tvůrce si prošel své logy a zjistil, že 96 % jeho tokenů tvořilo opakované čtení historie.

Jak se to počítá

Vaše 1. zpráva stojí to, co jste napsali.

Vaše 10. zpráva stojí to, co jste napsali + všech devět zpráv před ní (znovu se odešlou).

Příklad: Čtete soubor o velikosti 3 000 tokenů. Pokud to děláte v 4. kroku session, která trvá 40 kroků celkem, bude vám tento soubor vyúčtován ještě 36krát — jednou při psaní, pak při každém dalším kroku. Sečteno: 3 000 × 37 = 111 000 tokenů za jeden soubor.

Cachování (Prompt Caching) — řešení problému

Cachování (automatické prompt caching v Claude Code) dělá opakované čtení levným — stojí asi desetinu plné ceny. Když cache porušíte (změníte model, odpojíte MCP server, delší pauza), vše se znovu zpracuje za plnou cenu. Většina oprav níže je právě o tom, cache neporušovat.

Lifetime cache — jak dlouho trvá

U API: ~5 minut. U předplatného (Pro/Max): ~1 hodina. Cache je časovač, ne uložený soubor — když si dáte dlouhou pauzu, cache vyprší a první zpráva po návratu si znovu načte vše za plnou cenu.

Čtyři opravy, které udělají majoritu práce

1

/clear mezi úkoly

Všechny ostatní opravy zmenší pouze určitou část kontextu. Příkaz /clear resetuje celý základ, ze kterého se tyto části počítají — a stojí nula tokenů.

Postup: Nejdříve spusťte /rename (pojmenujte session, aby jste se k ní mohli později vrátit přes /resume), pak /clear. Nezmazali jste svou práci — jen jste zabránili dalšímu úkolu, aby si ji táhl s sebou.

2

Nikdy neměňte model, úroveň úsilí nebo fast mode uprostřed session

Model je součástí klíče pro cache. Pokud ho změníte, celá vaše historie se znovu zpracuje za plnou cenu. Příklad: Kontext 200k na modelu Opus se tak z odpovídajícího kroku za 10 centů stane krok za $1.

Past: Lidé přepnou z Opus na Sonnet aby ušetřili, a zaplatí 10× více za to, že cache zanikne.

3

Zmenšete načítaný základ (preload)

Spusťte /context v novém chatu. Vše, co je tam uvedeno, vám bude účtováno při každé zprávě v každé session.

Co ovládat:

  • CLAUDE.md — Globální v ~/.claude/CLAUDE.md, projektový v kořeni. Udržujte jej pod 200 řádky. Kontrola: wc -l ~/.claude/CLAUDE.md ./CLAUDE.md
  • MCP servery — Napište /mcp pro jejich výpis. Odstraňte: claude mcp remove <název>. Aplikace Claude: Nastavení → Konektory → Odpojit.
  • Skills (Dovednosti) — Popis každé dovednosti se načítá do každé session. Smažte ty, které nikdy nepoužíváte. Zkraťte příliš dlouhé popisy.
  • Tool deferral — Zkontrolujte řádek tools v příkazu /context — uvádí deferred? Pokud ano, manuály k nástrojům zůstávají skryté dokud nejsou použity (~85 % úspory). V novějších verzích je zapnuto výchozí.
4

Filtrujte výstup nástrojů dříve, než se uloží do kontextu

Jediný příkaz npm install vypíše do kontextu 800 řádků. Vy z toho nic nepřečtete, ale platíte za vše — při každém dalším kroku, dokud neuděláte /clear.

Master Prompt níže nainstaluje hook, který zkrátí výstup příkazů na posledních 30 řádků plus řádky s chybami. Nástroje jako RTK měří úsporu 60–90 %; jeden tvůrce naměřil 92 % úsporu na svém nastavení.

FÁZE 3 — REPORT
════════════════════════════════════════════════════════════════════════════════

Ukaž stav PŘED/PO:
- Preload tokeny
- Velikost CLAUDE.md
- % plýtvání na re-read

Poté VYRENDRUJ kartičku "5 návyků" (viz níže v příručce):
- /clear mezi úkoly
- Vyber model + effort jednou, nikdy neměň uprostřed session
- Seskupuj dotazy do jedné zprávy
- Upravuj zprávu místo posílání oprav
- Vkládej text, nikdy PDF ani obrázky s textem

Udělej to v krásném designu.

Pět návyků, které ti ušetří nejvíc

1. /clear mezi úkoly

Nová session, nový kontext, nula starého vybavení. Mezi projekty, mezi úkoly, zvláště když skončíte s jednou věcí a začínáte s druhou.

2. Zvolte model jednou

Na začátku session si zvolte model — a nikdy to neměňte uprostřed. Model je součástí cache klíče.

3. Seskupujte dotazy

Pět malých otázek = pět procesů cache. Jedna velká otázka se jmény všech podbodů = jeden proces.

4. Upravujte zprávu

Místo posílání oprav: /edit vaši zprávu, pak znovu spusťte claude. Cache zůstane nedotčená.

  • 5. Vkládejte text, nikdy PDF nebo obrázky — Snímek obrazovky (4K) = ~5 000 tokenů. Text = jejich čtvrtina. A model v obrázku nemůže provádět úpravy — vždy text.

Output Style: ELI5 — Zjednodušená technická čeština

Výstup vám účtuje tokeny dvakrát: jednou při napsání a podruhé v každém dalším kroku jako součást historie. Standardní rady typu "přidejte be concise" jsou vágní — model sám rozhoduje co je stručné.

Místo toho: ASD-STE100 Simplified Technical English — standard leteckého psaní. Cca 900 schválených slov, činný rod, jedna instrukce na větu. Vytvořeno aby i vyčerpaný mechanik dokázal číst rychle a jednat. Přesně to, co chcete v 11 hodin večer.

Strategie výběru modelů — který model kdy

Pravidlo: Nejjednodušší model, který zvládne danou práci. Ale nikdy neměňte model uprostřed session — směrujte práci přes skills a pod-agenty, což ponechá cache nedotčenou.

ModelVhodný na…CenaJak nasadit
HaikuMechanika: přejmenování, formátování, sumarizace, web scraping, hromadné operace1–5 USD/MTokNapevno do pod-agentů a skills. Nikdy ne jako hlavní session.
SonnetBěžné úkoly, refaktoring, standardní funkce, rutinní dny3–15 USD/MTokSession zaměřená na rutinní práci. Výchozí pro začátečníky.
OpusArchitektura, debugging, vše co vyžaduje úsudek, dlouhé session5–25 USD/MTokVýchozí model pro důležité session.
FableDesign, nejsložitější úvahy, vše kde záleží na vkusu10–50 USD/MTokVyhrazené session pro design, top priority.

Žebříček krok za krokem

  • Zůstáváte v Claude: Hlavní session Opus. Haiku v skills/pod-agentech. Sonnet pro rutinu. Fable pro design. Nula přepnutí uprostřed session.
  • Kdy odejít na Codex: Exekuce náročná na tokeny, kde je plán hotový. Claude = ověřování, Codex = rychlý výstup. Až 4× méně tokenů. Dvě předplatná = dva rozpočty.
  • Kdy odejít na DeepSeek/GLM: Objemná práce s nízkým rizikem — masivní refaktoring, batch, noční běhy. Kapacita na token > kvalita.

Dlouhé pauzy a cache — kritické!

Pokud si dáte delší pauzu u session s 200k kontextem, cache vyprší dříve než se vrátíte. Cache je časovač, ne uložený soubor — cca 1 hodina u předplatného. Když si berete delší pauzu, /clear před odchodem — cache kterou se snažíte chránit stejně vyprší dříve, než se vrátíte.

Mýty a jejich pravdy

❌ Mýtus

/compact šetří tokeny

✓ Pravda

/compact znovu odešle celou konverzaci aby ji sumarizoval (nejrozdávanější zpráva) a pak smaže cache. Kontinuita bez úspory.

❌ Mýtus

Pište kratší prompty

✓ Pravda

Vaše psaní = ~0,01 % účtu. Vágní prompty stojí kvůli předělávání, ne délce.

❌ Mýtus

Pod-agenti šetří tokeny

✓ Pravda

Tokeny se přesouvají. Každý pod-agent má svůj systém prompt, paměť, nástroje. Vyplatí se jen u dlouhých session.

❌ Mýtus

Obrázek s textem šetří tokeny

✓ Pravda

Obrázek není levnější. A model v obrázku nemůže editovat. Vždy text.

  • Soubory v cache navždy? Ne — cache trvá 5 minut až 1 hodina. Dlouhé pauzy = opakované zpracování za plnou cenu.
  • Claude Code v pozadí čerpá limity? Ne — nečinný běh stojí <4 centy. Skutečný únik je v úlohách a týmech agentů.

Ruční nastavení — 60 vteřin práce

Tři věci která se dělají jednou a pak fungují automaticky:

  • Odpojte nepoužívané konektory: V aplikaci: Nastavení → Konektory. Nebo CLI: claude mcp remove <název>
  • Nastavte úsilí na začátku: Platí stejné pravidlo cache. Zvolte jednou, neměňte.
  • Zapněte statusline: Master Prompt ji nastaví. Živý ukazatel nákladů změní vaše chování více než jakékoli pravidlo.

Bonusová sekce: Designérská práce — kde tokeny mizí nejrychleji

Designové session jsou nejdražší — zpětná vazba funguje na snímcích a přepisování souborů. Jeden snímek = ~2 700 tokenů. 4K = ~5 000. 30 iterací se snímky = 100k+ tokenů jen v pixelech.

  • Kodifikujte vkus jedorázově: Design style guide jednou — paleta, typografie, mezery, ~2 KB. Každá další session jej načte.
  • Reference → specifikace: Máte web? Extrahujte do souboru. Dále předávejte specifikaci, ne referenci.
  • Kritici s čistým kontextem: Pod-agenti posoudí vzhled ve svém kontextu, vrátí verdikty jako text (levné).
  • Text před pixely: Nejdříve DOM a CSS. Snímek až když text nestačí.
