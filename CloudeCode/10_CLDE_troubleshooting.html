Troubleshooting

Přehled nejčastějších chyb a jejich řešení — od instalace přes autentizaci až po situace, kdy Claude bloudí nebo spotřebovává příliš mnoho tokenů.

Instalační chyby

command not found: claude

Po instalaci příkaz claude systém nenachází. PATH není nastavena správně nebo instalace se nezapsala do shellu.

Spusťte source ~/.zshrc nebo source ~/.bashrc (podle vašeho shellu) a zkuste znovu. Pokud nepomůže, restartujte terminál. Na macOS zkontrolujte echo $PATH — musí obsahovat ~/.local/bin nebo adresář z výstupu instalátoru.
EACCES: permission denied při npm instalaci

Npm se pokouší zapisovat do systémového adresáře, ke kterému nemáte oprávnění. Typické na macOS bez správně nastaveného npm prefix.

Přejděte na nativní instalátor: curl -fsSL https://claude.ai/install.sh | bash. Nevyžaduje sudo ani změny npm prefixu.
Error: Node.js version X.X is not supported

Pokud stále používáte npm instalaci, Claude Code vyžaduje Node.js 18 nebo novější.

Nainstalujte Node.js přes nvm: nvm install 20 && nvm use 20. Nebo přejděte na nativní instalátor, který Node.js nevyžaduje.
winget : No package found matching input criteria

WinGet nenachází balíček Anthropic.ClaudeCode. Obvykle jde o zastaralou verzi WinGet nebo zpoždění v aktualizaci katalogu.

Aktualizujte WinGet: winget upgrade winget. Alternativně stáhněte instalátor přímo z claude.com/download.

Autentizační chyby

Authentication failed: invalid API key

API klíč v ENV proměnné je neplatný, vypršel nebo byl zrušen.

Přihlaste se na console.anthropic.com → API Keys → zkontrolujte aktivní klíče. Vygenerujte nový klíč a aktualizujte ~/.zshrc: export ANTHROPIC_API_KEY="sk-ant-nový-klíč", pak source ~/.zshrc.
Login loop — browser otevře ale nevrátí token

Autentizace přes předplatné (claude auth login) spustí prohlížeč, ale po přihlášení se token nepřenese do CLI. Obvyklé na Linux nebo při nestandardním nastavení prohlížeče.

Zkuste claude auth login --print-redirect-url — zobrazí URL s tokenem, který zkopírujete ručně. Nebo použijte API klíč jako alternativu: export ANTHROPIC_API_KEY="sk-ant-...".
Error: You are not subscribed to Claude Code

Váš plán nezahrnuje Claude Code. Týká se to zejména Team Standard ($20/seat) a Free plánu.

Claude Code je dostupný od Pro ($20/měs) nebo Team Premium ($100/seat). Přejděte na claude.com/upgrade a upgradujte plán.

Limity a rate limiting

Claude Code limit reached — please wait

Dosáhli jste limitu token budgetu pro aktuální 5hodinové okno (Pro plán ~44 000 tokenů, Max plán závisí na tieru). Claude Code přestane odpovídat nebo zobrazí varovnou hlášku.

Počkejte na reset okna (zobrazí se zbývající čas v /status). Nebo zapněte Extra Usage v nastavení předplatného — Claude Code bude pokračovat za API sazbu s vaším nastaveným měsíčním stropem.
429 Too Many Requests (API users)

Překročili jste rate limit API. Každý tier (Free, Build, Scale) má jiné limity — počet požadavků za minutu a tokeny za minutu (TPM).

Claude Code má automatický retry s exponential backoff — počkejte chvíli, zkusí to sám. Pokud limit narážíte pravidelně, upgradujte API tier v Anthropic Console nebo optimalizujte prompty (viz díl 01, sekce Jak ušetřit).

Claude bloudí — co dělat

Jedním z nejčastějších problémů není technická chyba, ale behaviorální: Claude začne dělat věci, které jste nezamýšleli, nebo se opakovaně vrací ke stejné nesprávné implementaci.

Příznaky bloudění

  • Claude opravuje bug → vytvoří nový bug → opravuje nový bug → smyčka
  • Claude ignoruje váš požadavek a dělá "lepší" řešení po svém
  • Claude tvrdí, že soubor upravil, ale změny nejsou vidět
  • Claude generuje stále delší a delší odpovědi bez pokroku

Jak z toho ven

Postup při bloudění
# Krok 1: Zastavte agenta
Ctrl+C

# Krok 2: Vyčistěte kontext
/clear

# Krok 3: Zkontrolujte stav projektu
git diff   -- co Claude skutečně změnil
git status

# Krok 4: Vraťte nežádoucí změny
git checkout -- .   -- zahodí všechny uncommitted změny

# Krok 5: Restartujte s přesnějším zadáním
claude
-- napište konkrétnější prompt, viz tipy níže

Jak napsat lepší prompt aby Claude nebloudil

  • Specifikujte soubory explicitně: "Uprav POUZE soubor src/auth/login.ts, jiné soubory neměň."
  • Definujte co NECHCETE: "Nerefaktoruj existující kód, jen přidej validaci emailu."
  • Použijte Plan mode: /plan nejdřív — Claude vysvětlí záměr, vy schválíte nebo opravíte před psaním kódu.
  • Rozdělte velký úkol: "Přidej pouze type definice" → schválit → "Teď implementuj funkce" → schválit → "Napiš testy".
  • Dejte příklad: "Podobně jako funkce validateEmail na řádku 45, přidej validatePhone."

Debugging session — diagnostické příkazy

Diagnostika při problémech
# Verze a aktuální stav
claude --version
claude --help

# V session — přehled kontextu a tokenů
/context    -- jaké soubory jsou načteny, kolik tokenů
/status     -- zbývající budget (Pro/Max uživatelé)
/cost       -- aktuální náklady session (API uživatelé)

# Verbose logging — detailní výpis co Claude dělá
claude --verbose

# Resetovat konfiguraci na výchozí
claude config reset

# Zkontrolovat logy
ls ~/.claude/logs/
cat ~/.claude/logs/session-$(date +%Y%m%d).json | python3 -m json.tool

Windows specifické problémy

Bash příkazy selhávají na Windows

Claude Code interně používá Git Bash pro spouštění příkazů. Pokud Git Bash není nainstalovaný nebo není v PATH, bash příkazy selžou.

Nainstalujte Git for Windows z git-scm.com. V instalaci vyberte "Git Bash" a "Add to PATH". Pak nastavte: CLAUDE_CODE_GIT_BASH_PATH="C:\Program Files\Git\bin\bash.exe" v systémových proměnných.
Znaky se zobrazují špatně — lomená čeština

Windows cmd a starší PowerShell používají kódování CP1250 místo UTF-8, což způsobuje rozsypaný text.

Spusťte: chcp 65001 v cmd/PowerShell pro přepnutí na UTF-8. Nebo používejte Windows Terminal (moderní terminál) — ten UTF-8 zvládá správně z výroby.

Kde hledat pomoc a hlásit bugy

  • Oficální dokumentace: docs.anthropic.com/en/docs/claude-code — první zastávka, často obsahuje řešení
  • GitHub Issues: github.com/anthropics/claude-code — hlášení bugů, sledování known issues
  • Anthropic Discord: Server #claude-code kanál — komunita vývojářů, rychlé odpovědi
  • Support ticket: support.anthropic.com — pro platební problémy a account issues
  • In-app reporting: příkaz /bug v Claude Code session — pošle kontext přímo Anthropic
  • Reddit: r/ClaudeAI — neoficiální, ale aktivní komunita s praktickými tipy
Tip při hlášení bugu

Přiložte výstup claude --version, operační systém, a pokud možno výstup claude --verbose ze session, kde chyba nastala. To drasticky urychlí diagnostiku ze strany Anthropic.
