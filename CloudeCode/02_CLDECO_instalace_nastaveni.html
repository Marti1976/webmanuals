DÍL 02

Instalace & Nastavení

Claude Code má tři způsoby, jak ho spustit — a k tomu vám chybí pár souborů, aby koukal na váš projekt správně.

Tady se dozvíte, jak nainstalovat Claude Code do vašeho terminálu, jak ho nakonfigurovat přes CLAUDE.md a settings.json, a jak nastavit oprávnění tak, aby Claude věděl, co smí a nesmí dělat.

Přehled rozhraní

Claude Code běží ve třech prostředích, každé má jiný use-case:

Doporučení pro začátek: Nainstalujte CLI, pak si vyzkoušejte VS Code plugin. Oba se sdílí stejnou konfigurací (CLAUDE.md, settings.json, oprávnění).

CLI instalace

Claude Code v terminálu se instaluje přes npm (globálně) nebo přes Homebrew (macOS).

Instalace přes npm (všechny OS)
# Globální instalace
npm install -g @anthropic-ai/claude-code

# Ověření instalace
claude --version

# Přihlášení (otevře OAuth browser)
claude auth login

# Začátek — první session v terminálu
claude "Přepiš tenhle Python soubor do moderního Pythonu"
Instalace přes Homebrew (macOS, Linux)
brew install anthropic/claude-code/claude

# Ověření a přihlášení (stejně jako npm)
claude auth login

Poznámka k Node.js: Potřebujete Node.js 18+ (ověřte node --version). Není třeba nic jiného.

CLAUDE.md — instrukce pro projekt

CLAUDE.md je soubor v kořeni vašeho projektu, který říká Claudovi, jak přistupovat k vašemu kódu. Je to jako system prompt, ale specifický pro váš projekt.

Bez CLAUDE.md si Claude hádá — s dobrým CLAUDE.md ví přesně, co má dělat.

Příklad CLAUDE.md — minimální verze
# Instrukce pro Claude Code v projektu MyApp

## Konvence projektu
- Používáme TypeScript, všechny funkce musí mít type hints
- Testy píšeme do `tests/` složky, formát: `*.test.ts`
- Git commit zprávy: Imperative mood, max 50 znaků ("Fix bug in auth", ne "Fixed")

## Co musím vědět
- Projekt je monorepo s `apps/` a `packages/` složkami
- Databáze je PostgreSQL, schema v `db/migrations/`
- API běží na portu 3000, frontend na 3001

## Omezení
- Nikdy neměň `db/seed.ts` — obsahuje testovací data
- Ne přes `/eslint` nebo `/prettier` — ty jsou spuštěny v CI
- Nepojívej ES5, vždy minimálně ES2020 syntax

## Užitečné příkazy
```
npm run dev       — vývojová Build + watch
npm run test      — spustí testovací suite
npm run typecheck — kontrola TypeScript
git status        — stav repo
```

Doporučená struktura CLAUDE.md:

  • Konvence kódu — jaký jazyk, formát, pojmenování
  • Architektura projektu — kde je co, jak je to zorganizované
  • Příkazy pro běžné úkoly — co spustit na test, build, lint
  • Omezení a pravidla — co Claude nesmí dělat, co je zákazáno
  • Důležité soubory — které soubory jsou kritické (neměnit)
Pro týmy

CLAUDE.md commitujte do repozitáře. Každý vývojář si jej přečte a všichni mají stejné instrukce pro Claude. Nemusíte je psát v každé session.

settings.json — konfigurace session

Soubor .claude/settings.json (v projektu) nebo ~/.claude/settings.json (globální) určuje technické nastavení: model, rate limity, oprávnění, ENV proměnné.

Kompletní settings.json — s vysvětlením
{
  // Výchozí model pro session
  "model": "claude-sonnet-4-6",

  // ENV proměnné dostupné v session
  "env": {
    "MAX_THINKING_TOKENS": "8000",
    "NODE_ENV": "development",
    "DATABASE_URL": "postgresql://localhost/myapp_dev"
  },

  // Oprávnění příkazů
  "permissions": {
    "allow": [
      "Bash(npm run test)",
      "Bash(npm run test:*)",
      "Bash(npm run lint)",
      "Bash(npm run build)",
      "Bash(git status)",
      "Bash(git diff)",
      "Bash(git log --oneline -20)",
      "Bash(git add -p)"
    ],
    "deny": [
      "Bash(git push origin main)",
      "Bash(git push --force*)",
      "Bash(rm -rf*)",
      "Bash(sudo*)",
      "Bash(npm publish*)",
      "Bash(DROP TABLE*)"
    ]
  },

  // MCP servery (viz díl 05)
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": { "GITHUB_TOKEN": "ghp_..." }
    }
  }
}

Allow vs Deny — jak fungují oprávnění

Systém oprávnění pracuje na principu: vše, co Claude navrhne spustit, se buď automaticky schválí (allow), automaticky zablokuje (deny), nebo vyžaduje vaše ruční potvrzení (výchozí).

  • allow — příkazy bezpečné pro automatické schválení. Sem patří testování, linting, čtení stavu Gitu. Claude je spustí bez potvrzení, což urychluje práci.
  • deny — příkazy, které Claude nesmí ani navrhnout. Destruktivní operace, push do main, sudo. Tvrdá pojistka, která platí vždy.
  • Wildcards — hvězdička matchuje cokoli za ní. Bash(npm run test:*) povolí všechny varianty test příkazů.
  • Výchozí — vše ostatní vyžaduje ruční potvrzení ve formě [y/n] v terminálu.
Nikdy do allow

Do allow nepatří: git push, rm, sudo, příkazy měnící produkční data, npm publish. Tato pravidla neexistují pro pohodlí, ale jako záchranná síť před chybou agenta.

Proměnné prostředí

ENV proměnné lze nastavit třemi způsoby — v shellu (pro přihlašování), v settings.json (pro session kontext) nebo přes export v shellu před spuštěním Claude.

Klíčové ENV proměnné · ~/.zshrc nebo ~/.bashrc
## Autentizace (alternativa k claude auth login)
export ANTHROPIC_API_KEY="sk-ant-api03-..."

## Omezení thinking tokenů — výchozí je neomezeno!
export MAX_THINKING_TOKENS=8000

## Výchozí model (přepíše settings.json)
export ANTHROPIC_MODEL="claude-sonnet-4-6"

## Windows — cesta ke Git Bash (pokud není v PATH)
export CLAUDE_CODE_GIT_BASH_PATH="/c/Program Files/Git/bin/bash.exe"

## Disable auto-update (pokud používáte verzi pin v CI)
export CLAUDE_CODE_DISABLE_AUTO_UPDATE=1

## Logování na verbose úroveň (pro debugging)
export CLAUDE_CODE_LOG_LEVEL="debug"

Hierarchie priorit — přehled

Když Claude Code načítá konfiguraci, aplikuje ji v tomto pořadí (vyšší číslo = vyšší priorita, přepíše nižší):

  • 1. Globální settings ~/.claude/settings.json — vaše osobní výchozí nastavení
  • 2. Globální CLAUDE.md ~/.claude/CLAUDE.md — vaše osobní instrukce (styl, preference)
  • 3. Projektové settings .claude/settings.json — nastavení konkrétního projektu
  • 4. Projektové CLAUDE.md CLAUDE.md v kořeni projektu — instrukce projektu
  • 5. Lokální přepisy .claude/settings.local.json — vaše osobní lokální odchylky (nepushovat!)
  • 6. CLI přepínače — --model, --auto-approve atd. — přepíší vše ostatní
Doporučení pro týmy

Commitujte do repozitáře: CLAUDE.md a .claude/settings.json. Do .gitignore přidejte: .claude/settings.local.json. Tím každý vývojář sdílí projektová pravidla, ale může si lokálně přepsat třeba výchozí model nebo výchozí oprávnění.
