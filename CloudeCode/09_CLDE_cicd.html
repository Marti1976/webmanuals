CI/CD & Automatizace

Claude Code není jen nástroj pro interaktivní práci — lze ho zapojit do celého pipeline jako automatizovaného účastníka, který code reviewuje, píše testy nebo generuje dokumentaci.

Co je CI/CD a proč s Claude Code

CI (Continuous Integration) je praxe, kdy se každá změna kódu automaticky otestuje před mergem. CD (Continuous Deployment) pak automaticky nasazuje otestovaný kód na server. Dohromady: váš kód nikdy "nehnije" v lokálním prostředí.

Claude Code do tohoto pipeline přidává inteligentní vrstvu — místo pouhého spouštění testů (pass/fail) dokáže kód skutečně číst, hodnotit kvalitu, navrhovat zlepšení a vysvětlit, proč test selhal a jak to opravit.

Claude Code v GitHub Actions

GitHub Actions je nejrozšířenější platforma pro CI/CD u GitHub projektů. Anthropic poskytuje oficální GitHub Action pro Claude Code integraci.

Předpoklad

Potřebujete Anthropic API klíč (ne předplatné). V GitHub repozitáři ho uložte jako secret: Settings → Secrets → New repository secret → ANTHROPIC_API_KEY.

Základní workflow soubor

.github/workflows/claude-review.yml
name: Claude Code Review

on:
  pull_request:
    types: [opened, synchronize]

jobs:
  claude-review:
    runs-on: ubuntu-latest
    permissions:
      contents: read
      pull-requests: write  # potřeba pro komentáře k PR

    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0  # celá Git historie

      - name: Claude Code Review
        uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
          model: claude-sonnet-4-6
          # Co má Claude udělat pro každý PR
          prompt: |
            Zreviewuj změny v tomto PR. Zaměř se na:
            1. Potenciální bugy nebo logické chyby
            2. Bezpečnostní problémy (SQL injection, XSS, odhalení dat)
            3. Výkonnostní problémy (N+1 dotazy, memory leaks)
            4. Srozumitelnost a udržovatelnost kódu
            
            Přidej komentáře přímo k relevantním řádkům.
            Pokud je PR v pořádku, napiš stručné schválení.

Automatické code review — pokročilé nastavení

Základní review je jen začátek. Můžete Clauda nastavit jako specializovaného reviewera pro různé aspekty — bezpečnost, výkon, test coverage nebo dodržování konvencí týmu.

Review zaměřené na bezpečnost

Prompt pro security review
prompt: |
  Jsi bezpečnostní reviewer. Prohledej tento PR pro:
  
  **Kritické** (blokuje merge):
  - SQL injection (nepoužívání prepared statements)
  - Přímé vkládání user input do HTML (XSS)
  - Odhalení API klíčů nebo hesel v kódu
  - Použití md5/sha1 pro hashování hesel
  
  **Varování** (doporučení):
  - Chybějící input validace
  - Příliš permisivní CORS nastavení
  - Logování citlivých dat
  
  Pro každý nález uveď: závažnost, řádek kódu, vysvětlení rizika, 
  konkrétní oprava.

@claude trigger — review na vyžádání

Místo automatického review na každý PR můžete Clauda zavolat manuálně tagem v komentáři:

Volání Clauda v PR komentáři
# Napište do komentáře PR:
@claude zreviewuj bezpečnost změn v auth modulu

# Nebo:
@claude napiš unit testy pro nové funkce v tomto PR

# Nebo:
@claude vysvětli proč testy selhávají a jak to opravit

Automatické generování testů

Claude Code dokáže generovat testy pro nový kód v každém PR — bez toho, aby to vývojář musel dělat ručně. To dramaticky zvyšuje test coverage bez přidané zátěže.

.github/workflows/generate-tests.yml
name: Generate Tests for New Code

on:
  pull_request:
    types: [opened]

jobs:
  generate-tests:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Nainstaluj závislosti
        run: npm ci

      - name: Generuj testy přes Claude
        uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
          prompt: |
            Podívej se na změněné soubory v tomto PR.
            Pro každou novou funkci nebo metodu bez testu:
            1. Napiš unit testy (Jest/Vitest syntax)
            2. Zahrň edge cases a error handling
            3. Ulož testy do příslušného __tests__ adresáře
            4. Ověř že testy procházejí (npm test)
            
            Pokud testy selhávají, oprav kód nebo testy
            dokud vše neprochází.

Automatická aktualizace dokumentace

Dokumentace zastarávání je klasický problém. Claude Code ho může řešit automaticky — při každém mergi do main zkontroluje, jestli se změnilo API nebo chování funkcí, a aktualizuje dokumentaci.

.github/workflows/update-docs.yml
on:
  push:
    branches: [main]
    paths:
      - 'src/**'           # spustí se jen při změně kódu
      - '!src/**/*.test.*'  # ale ne při změně testů

jobs:
  update-docs:
    steps:
      - name: Aktualizuj dokumentaci
        uses: anthropics/claude-code-action@v1
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
          prompt: |
            Porovnej změny od posledního commitu se soubory v docs/.
            Aktualizuj dokumentaci kde:
            - Přibyla nová funkce nebo parametr
            - Změnilo se chování nebo návratová hodnota
            - Byl opravený popsaný bug
            
            Commit změny v docs/ se zprávou "docs: auto-update"

Cloud Routines v CI kontextu

Cloud Routines (viz díl 06) lze kombinovat s GitHub Actions — Routine spustí agenta, který vytvoří PR s návrhem změn, a GitHub Actions PR automaticky otestuje.

  • Dependency updates Routine — každé pondělí Claude vytvoří PR s aktualizovanými závislostmi → GitHub Actions otestuje build → pokud testy prochází, PR jde automaticky do review.
  • Security scan Routine — každou noc prohledá závislosti → při nálezu High/Critical vytvoří GitHub Issue nebo PR s opravou.
  • Code quality Routine — každý pátek projde kód a navrhne refaktoring → vytvoří PR s komentářem "Tech debt — nízká priorita".

Náklady Claude v CI pipeline

Každý spuštěný workflow spotřebovává API tokeny. Pro tým s 10 vývojáři a 20 PR týdně se náklady rychle sčítají.

Kalkulace příkladu

Review jednoho PR (průměr 500 řádků kódu) spotřebuje zhruba 50 000–100 000 tokenů na Sonnet 4.6 ($3/MTok input). To je $0.15–0.30 na review. Při 20 PR týdně = $3–6 týdně = $12–24 měsíčně. Rozumné — ale nastavte monthly cap v Anthropic Console pro jistotu.
