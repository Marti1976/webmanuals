Příprava USB mSATA SSD

Jak nahrát obraz (image) Home Assistant OS na SSD disk pod Windows a připravit vše pro první spuštění. RPi 3 B+ umí bootovat z USB bez úprav a SD kartu nepotřebuje.

Co potřebuješ

Checklist před startem
PC s Windows 10 nebo 11 mSATA SSD v USB pouzdře Raspberry Pi 3 B+ Internetové připojení SD karta není potřeba (RPi 3 B+ bootuje z USB)

Software, který stáhneš nebo nainstaluješ:

  • Raspberry Pi Imager – zdarma, z raspberrypi.com/software. Na stránce klikni „Download for Windows“, spusť instalátor (Next → Install → Finish) a aplikaci spusť.

Boot z USB

Raspberry Pi 3 B+ umí bootovat z USB disku (USB boot) bez jakýchkoli úprav. Nemusíš nic povolovat ani programovat. Stačí nahrát Home Assistant OS na SSD (viz sekce 4.3) a RPi spustit bez SD karty.

ℹ️ Proč se jinde píše o povolení USB bootu?

Starší modely (Raspberry Pi 3 B, 3 A+ a 2 B v1.2) mají USB boot z výroby vypnutý a vyžadují jednorázový zápis nastavení do procesoru (OTP). U modelu 3 B+ podle dokumentace Home Assistant OS není potřeba. Pokud tedy narazíš na návody se SD kartou a Raspberry Pi OS, týkají se starších modelů.

Na co si dát pozor

  • Do slotu pro SD kartu nic nevkládej. Podle dokumentace Home Assistant OS musí být všechny bootovací SD karty vyjmuty.
  • První start z USB může trvat výrazně déle, protože RPi nejdřív zkouší SD kartu a teprve pak USB.
  • Některé USB disky pro boot nefungují. Pokud se RPi nespustí, zkus jiné pouzdro nebo jinou značku disku.
  • Některé SSD potřebují parametr „quirks“ (viz sekce 2.3).

Novější modely

🔼 Pro Raspberry Pi 4/5

U Raspberry Pi 4 aktualizuj bootloader na stabilní verzi s podporou USB bootu. Pokud nepoužíváš SD kartu, přidej do config.txt k dtparam hodnotu sd_poll_once=on (oddělenou čárkou). Raspberry Pi 5 je v Home Assistant OS zatím označen jako beta.

Nahrání Home Assistant OS

Teď nahrajeme (flash) samotný Home Assistant OS na mSATA USB SSD. Toto je bootovací disk systému.

🔴 Důležité upozornění

V Raspberry Pi Imager vybereš USB SSD jako úložiště. Všechna stávající data na SSD budou nenávratně smazána. Ujisti se, že vybíráš správné zařízení – zkontroluj název a velikost. Nikdy nevyber systémový disk Windows!

1
Připoj mSATA USB SSD k počítači

Zasuň mSATA SSD do USB pouzdra, připoj pouzdro k PC přes USB. Windows ho detekuje jako removable disk. Pokud se otevře průzkumník – zavři ho, disk bude přeformátován.

2
Otevři Raspberry Pi Imager a zvol zařízení

Spusť Raspberry Pi Imager. Klikni CHOOSE DEVICE → vyber Raspberry Pi 3. Názvy tlačítek se mohou podle verze Imageru mírně lišit.

3
Vyber Home Assistant OS jako operační systém

Klikni CHOOSE OS a naviguj:

  • → Other specific-purpose OS
  • → Home assistants and home automation
  • → Home Assistant
  • → Home Assistant OS – vyber nejnovější verzi určenou pro Raspberry Pi 3

Obraz (image) se automaticky stáhne z internetu (stovky MB). Nebo si ho stáhni ručně z github.com/home-assistant/operating-system/releases (hledej haos_rpi3-64-X.Y.img.xz) a použij „Use custom“.

Pozor na správný obraz: obraz pro Raspberry Pi 4 na RPi 3 nenabootuje.

4
Vyber USB SSD jako cílové úložiště

Klikni CHOOSE STORAGE → vyber svůj USB SSD disk.

Zkontroluj název a velikost! Typicky se bude jmenovat nějak jako "USB3.0 DISK" nebo název výrobce pouzdra. Pokud vidíš "Windows (C:)" nebo podobně – NEKLIKEJ NA TO!

5
Zapiš image na SSD

Klikni NEXT. Imager se zeptá na OS customisation – klikni NO (HA konfigurujeme přes webové rozhraní, ne zde).

Potvrď smazání: YES. Zápis začne – ukazatel průběhu zobrazí stav. NEODPOJUJ SSD!

  • Fáze zapisování: cca 3–8 minut (dle rychlosti USB)
  • Fáze ověřování: cca 2–5 minut

Po dokončení se zobrazí "Write Successful". Klikni Continue → zavři Imager.

6
Bezpečně odstraň USB SSD

Pravé tlačítko na ikoně USB v oznamovací oblasti (u hodin) → „Bezpečně odebrat hardware a vysunout médium“ (Safely Remove Hardware) → vyber SSD → Vysunout (Eject).

Počkej na potvrzení "Safe to Remove" a teprve pak fyzicky odpoj USB SSD od PC.

🔼 Pro Raspberry Pi 4/5

V Imageru zvol zařízení Raspberry Pi 4 nebo 5 a nabídne se odpovídající obraz (rpi4_64, rpi5_64). Obraz pro jiný model nebootuje.

Varianta B: ruční stažení obrazu a zápis v balenaEtcher

Pokud nechceš použít Raspberry Pi Imager, můžeš obraz stáhnout ručně a zapsat ho jiným programem:

  1. Stáhni haos_rpi3-64-X.Y.img.xz z github.com/home-assistant/operating-system/releases. Rozbalovat ho nemusíš.
  2. V programu balenaEtcher zvol Flash from file a vyber stažený soubor .img.xz.
  3. Jako cíl (target) vyber USB SSD, pečlivě zkontroluj název a velikost a klikni Flash.
  4. Po dokončení disk bezpečně odpoj stejně jako v kroku 6.

Časté situace ve Windows

Windows chce naformátovat disk po dokončení

Po úspěšném zápisu obrazu HAOS Windows zobrazí dialog "Je nutné naformátovat disk... před použitím". Klikni na Zrušit (Cancel)! Disk obsahuje Linux oddíly které Windows nerozezná, ale jsou správně zapsány. Neformátuj ho!

ℹ️ Proč Windows nabízí formátování?

HAOS používá Linux souborové systémy (ext4, FAT32 pro boot oddíl). Windows umí číst pouze FAT32 a NTFS – ostatní oddíly mu připadají "poškozené". Je to normální. Disk je správně zapsán a RPi ho bez problémů přečte.

Imager hlásí chybu při ověřování

Pokud se ověřování nezdaří, pravděpodobně:

  • Problémový USB kabel nebo port – zkus jiný USB port (preferuj USB 3.0, modrý)
  • Vadné USB pouzdro – otestuj jiným
  • Vadný SSD – vzácné, ale možné

Zkus znovu – Imager sám nabídne opakování.

SSD se v Imageru nezobrazuje

  • Odpoj a znovu zapoj USB kabel
  • Zkus jiný USB port (přímo na PC, ne přes hub)
  • Zkontroluj ve Správci zařízení (Device Manager) jestli se disk zobrazuje

Velikost oddílů

HAOS při prvním bootu automaticky rozšíří datový oddíl na celou dostupnou kapacitu SSD. Nemusíš nic dělat ručně.

  • 32 GB SSD: pro základní provoz stačí, po instalaci zůstává téměř celá kapacita pro data
  • 64 GB SSD: doporučeno, pokud plánuješ ukládat záznamy kamer nebo necháš databázi růst déle
  • 128 GB SSD: výrazný nadbytek pro základní HA, ale levné mSATA disky tuto kapacitu nabízejí

Struktura oddílů (partitions) po instalaci podle dokumentace HAOS (číslování sdaN se může lišit):

  • Boot (FAT32, malý oddíl) – jediný čitelný z Windows
  • Kernel A a System A – aktuální jádro a systém HAOS
  • Kernel B a System B – druhá sada pro aktualizace a návrat ke starší verzi (rollback)
  • Bootstate – stav bootování
  • Overlay – úpravy systému
  • Data (zbytek disku, /mnt/data) – zde jsou konfigurace, zálohy a databáze

Shrnutí

  • ✅ RPi 3 B+ připravené k bootu z USB (bez SD karty, bez nastavování OTP)
  • ✅ mSATA USB SSD s nahraným obrazem (image) Home Assistant OS
  • ✅ Vše připravené pro fyzické zapojení a první boot
