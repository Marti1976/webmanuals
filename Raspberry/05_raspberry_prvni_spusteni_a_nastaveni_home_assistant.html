První spuštění Home Assistant

Fyzické zapojení všech komponent, první boot z USB SSD, nalezení HA v síti a kompletní průvodce prvním nastavením (onboarding) – od vytvoření účtu po statickou IP adresu.

Fyzické zapojení

Pořadí zapojení je důležité. Napájení zapojuj vždy jako poslední – tím se RPi spustí. Vše ostatní musí být připojeno dřív.

Pořadí zapojení
1
💽 mSATA USB SSD
Zasuň do libovolného USB portu. Všechny čtyři porty RPi 3 B+ jsou USB 2.0 a sdílejí jeden řadič s Ethernetem, takže rozdíl mezi nimi není. SD karta nesmí být ve slotu.
2
📶 Zigbee USB koordinátor (SLZB-07)
Přes USB prodlužovací kabel (extension cable) 15–30 cm do druhého USB portu. Prodlužovák dongle vystrčí od kovové desky a zlepší Zigbee příjem.
3
🌐 Ethernet kabel
Jeden konec do RPi (RJ-45 port na krátké straně desky), druhý do routeru nebo Ethernet switche.
4
⚡ Napájecí zdroj (power supply, Micro-USB)
Jako poslední – tím se systém spustí. Použij kvalitní zdroj: minimum 5 V / 2,5 A, ideál 5,1 V / 3 A (viz sekce 2.2).
⚠️ Bez SD karty!

Do slotu pro SD kartu NIC nevkládej. RPi musí bootovat z USB SSD. Podle dokumentace Home Assistant OS musí být všechny bootovací SD karty vyjmuty, jinak se RPi může pokusit bootovat z nich místo z USB.

🔼 Pro Raspberry Pi 4/5

SSD zapoj do modrého USB 3.0 portu (rychlejší než USB 2.0). Zigbee dongle nech v USB 2.0 portu, USB 3.0 může rušit pásmo 2,4 GHz. Napájení je přes USB-C.

První boot

Po připojení napájení se spustí první boot. Tento proces trvá výrazně déle než normální start – systém se rozbaluje, konfiguruje a nastavuje. Buď trpělivý.

  • 🟡 První minuty: RPi bootuje HAOS z USB SSD. Z USB to může trvat déle než ze SD karty.
  • 🟡 Pak: systém se připraví a stáhne aktuální verzi Home Assistant Core (asi 700 MB, záleží na rychlosti internetu). Na webu uvidíš stránku „Preparing Home Assistant“.
  • 🟢 Obvykle po 10–25 minutách: systém je připraven a objeví se průvodce prvním nastavením (orientační odhad).
🔴 Nejdůležitější pravidlo prvního bootu

NIKDY nepřerušuj napájení během prvního bootu! Systém zapisuje databázi, konfiguraci a soubory. Přerušení může způsobit poškození dat a budeš muset celý proces opakovat od začátku.

Kontrolky RPi 3 B+ při bootu

Kontrolky na desce poznají jen základní stavy. Zelená kontrolka ACT souvisí hlavně s přístupem k SD kartě, takže při bootu z USB SSD nemusí svítit ani blikat a není to chyba.

  • Červená kontrolka (PWR): svítí trvale = napájení v pořádku. Nesvítí nebo bliká = problém s napájením, zkontroluj zdroj a kabel (viz sekce 2.2).
  • Zelená kontrolka (ACT): ukazuje hlavně přístup k SD kartě. Při bootu z USB SSD proto její chování o stavu systému nic neříká.
  • Ethernetový konektor: má dvě kontrolky, žlutá = připojený kabel (link), zelená = provoz (activity). Pokud nesvítí žádná, zkontroluj kabel a router.
  • Spolehlivá kontrola: seznam zařízení v routeru (zařízení „homeassistant“) nebo monitor připojený přes HDMI. Na monitoru uvidíš průběh startu a konzoli Home Assistant OS.

Nalezení IP adresy

Adresa homeassistant.local funguje přes mDNS (multicast DNS) a nemusí fungovat na všech sítích (zejména starší routery). Jako zálohu si zjisti přímou IP adresu (IP address).

Od Home Assistantu 2026.8 běží nové instalace Home Assistant OS na portu 80, takže adresa nemá číslo portu. Starší instalace používají port 8123. Pokud jedna adresa nefunguje, zkus druhou.

🌐 Přes webové rozhraní routeru

Přihlaš se do routeru (obvykle 192.168.0.1). Najdi seznam připojených zařízení (DHCP clients / Connected devices). Hledej zařízení s názvem "homeassistant" nebo "hassio". Poznamenej si IP adresu.

🔍 Přes network scanner

Na Windows: stáhni Advanced IP Scanner (zdarma) nebo použij nmap. Spusť sken lokální sítě (např. 192.168.0.0/24) a hledej zařízení s hostname "homeassistant".

🖥️ Přes monitor (HDMI)

Zapoj monitor přes HDMI ještě před zapnutím RPi. Po startu se na obrazovce zobrazí konzole Home Assistant OS s IP adresou.

📡 Příkazem ping

V příkazovém řádku Windows spusť ping homeassistant.local. V odpovědi uvidíš IP adresu. Funguje jen tam, kde funguje mDNS.

Jakmile máš IP adresu (např. 192.168.0.11), přistupuj přes:

http://192.168.0.11         (nové instalace od verze 2026.8)
http://192.168.0.11:8123    (starší instalace)

Průvodce prvním nastavením

Po otevření adresy z předchozí sekce se nejdřív zobrazí stránka „Preparing Home Assistant“, během které se stahuje aktuální verze Home Assistant Core (asi 700 MB). Pak se objeví průvodce. Projdeme ho krok za krokem:

ℹ️ Uživatelské jméno lze později změnit

Zvol ho přesto pečlivě. Musí být z malých písmen a bez mezer (doporučuji i bez diakritiky, např. admin). Později ho může změnit vlastník účtu (owner): Nastavení → Osoby → vybrat osobu → Upravit u uživatelského jména (Settings → People → Edit).

1
Uvítací obrazovka

Zobrazí se "Welcome to Home Assistant". Klikni „Vytvořit můj chytrý domov“ (Create my smart home).

2
Vytvoření účtu správce

Toto je tvůj hlavní přihlašovací účet – uložit bezpečně!

  • Jméno (Name): tvoje jméno, zobrazuje se v rozhraní
  • Uživatelské jméno (Username): přihlašovací jméno z malých písmen bez mezer (např. admin)
  • Heslo (Password): min. 16 znaků, kombinace písmen, čísel a symbolů
  • Potvrzení hesla: zadej znovu

Klikni „Vytvořit účet“ (Create account). Heslo si zapiš do bezpečného místa (správce hesel, password manager).

3
Poloha domácnosti

Home Assistant se pokusí určit polohu z IP adresy. Zkontroluj ji, případně klikni na mapu nebo zadej adresu (stačí přibližně, město nebo čtvrť). Z polohy se odvozuje časové pásmo, systém jednotek a měna a vytvoří se zóna Domov (Home) s poloměrem 100 m. Ta se používá například pro astronomické automatizace (západ a východ slunce) a přítomnost doma.

  • Časové pásmo: Europe/Prague
  • Systém jednotek: metrický
  • Měna: CZK

Po nalezení polohy klikni Next. Hodnoty můžeš později změnit v nastavení.

4
Anonymní analytika

Home Assistant se zeptá, zda posílat anonymní data o používání (Analytics). Je to dobrovolné. Vše můžeš nechat vypnuté a systém funguje stejně. Nastavení lze později změnit.

5
Nalezená zařízení

HA může nabídnout automaticky nalezená zařízení v síti (Philips Hue Bridge, Sonos, Chromecast...). Přidávat je teď nemusíš. Zařízení přidáme později, Zigbee zařízení přes Zigbee2MQTT.

6
Dokončení průvodce

Klikni „Dokončit“ (Finish). Jsi přihlášen do Home Assistant! Uvidíš hlavní ovládací panel (dashboard) s názvem Přehled (Overview).

Výchozí dashboard je prázdný – to je v pořádku. Karty a widgety přidáme po nastavení Zigbee zařízení.

Varianta B: obnovení ze zálohy (restore)

Pokud už máš zálohu dřívější instalace (viz kapitola 12), můžeš místo vytváření nového účtu zvolit na úvodní obrazovce Obnovit ze zálohy (Restore from backup), v novějších verzích Nahrát zálohu (Upload backup). Nahraj soubor zálohy, vyber, co obnovit, zadej šifrovací klíč (encryption key) a klikni Obnovit zálohu (Restore backup). Home Assistant obnoví účty, nastavení i doplňky/aplikace (add-ons/apps). Pak pokračuj od sekce 5.5.

Pevná IP adresa

DHCP router přiděluje IP adresy dynamicky – po restartu se může IP RPi změnit. Pro server, který běží 24/7, chceme pevnou IP (static IP), aby záložky v prohlížeči vždy fungovaly.

Varianta A – Rezervace v routeru (nejlepší způsob)

Přidej do routeru DHCP rezervaci: Router vždy přidělí konkrétní IP konkrétní MAC adrese RPi. Výhoda: nakonfigurováno v jednom místě, funguje i po přeinstalaci HAOS.

  1. Přihlaš se do routeru (obvykle 192.168.0.1)
  2. Najdi seznam DHCP klientů – hledej "homeassistant"
  3. Zkopíruj MAC adresu RPi (formát: b8:27:eb:xx:xx:xx)
  4. Najdi sekci DHCP Reservations / Static IP / IP Binding (název závisí na routeru)
  5. Přidej rezervaci: MAC adresa → zvolená IP (např. 192.168.0.11)
  6. Ulož. RPi dostane novou adresu po restartu (nebo po obnovení přidělení adresy v routeru)
💡 Jakou IP zvolit?

Zvol IP mimo DHCP rozsah routeru. Zjistíš ho v nastavení routeru (obvykle 192.168.0.100–192.168.0.254). Dobrá volba: 192.168.0.11 nebo 192.168.0.10 – tyto adresy DHCP obvykle nepřiděluje.

Varianta B – Nastavení přímo v Home Assistant

Pokud nemáš přístup do routeru nebo chceš nastavit IP přímo v HAOS:

  1. Jdi do Nastavení → Systém → Síť (Settings → System → Network)
  2. Klikni na rozhraní eth0 (Ethernet)
  3. Přepni z "Automatic (DHCP)" na "Static"
  4. Vyplň:
    • IP adresa: 192.168.0.11/24 (nebo dle tvé sítě)
    • Brána (Gateway): 192.168.0.1 (adresa routeru)
    • DNS: 192.168.0.1 (router) nebo 1.1.1.1 (Cloudflare)
  5. Ulož. Spojení se na chvíli přeruší a RPi bude mít pevnou IP
ℹ️ Po nastavení statické IP

Aktualizuj záložku v prohlížeči na novou adresu (např. http://192.168.0.11, u starších instalací http://192.168.0.11:8123). Přístup přes hostname homeassistant.local bude nadále fungovat.

Od verze 2026.8 jde port změnit v Nastavení → Systém → Síť. Pokud změnu do pěti minut nepotvrdíš, Home Assistant se automaticky vrátí k původnímu portu.

Nastavení WiFi

Pokud nemůžeš přivést Ethernet kabel, Home Assistant OS podporuje WiFi připojení. RPi 3 B+ zvládá WiFi 2,4 i 5 GHz. Konfiguruje se po prvním spuštění přímo v rozhraní HA.

  1. Jdi do Nastavení → Systém → Síť
  2. Klikni na + Přidat síť nebo na bezdrátové rozhraní wlan0
  3. Zadej SSID (název WiFi sítě) a heslo
  4. Ulož – RPi se připojí k WiFi
  5. Po připojení k WiFi lze Ethernet kabel odpojit
⚠️ Ethernet je vždy lepší volba

Pro server běžící 24/7 doporučuji Ethernet. WiFi může mít výpadky, vyšší latenci a problémy při rušení. Pokud WiFi použiješ, zvol pásmo 5 GHz, aby nerušilo Zigbee v pásmu 2,4 GHz. Ethernet je stabilnější a pásmo 2,4 GHz nezatěžuje.

  • ✅ Nastavena poloha, časová zóna a jednotky
