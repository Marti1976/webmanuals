01

Jak vstoupit do BIOSu

Ihned po zapnutí počítače (před načtením operačního systému) použij jeden z těchto způsobů:

  • Zmáčkni klávesu Delete nebo F2 při POST obrazovce (logo ASUS).
  • Alternativně: ve Windows 10/11 jdi do Nastavení → Aktualizace → Obnovení → Rozšířené spuštění → Restartovat nyní → Poradce při potížích → Rozšířené možnosti → Nastavení firmwaru UEFI.
  • Zmáčkni tlačítko Reset na šasi – okamžitě drž Delete.
⚠ Nesprávné nastavení BIOSu může způsobit nestabilitu nebo nespustitelnost systému. Pokud si nejsi jistý, použij F5 pro načtení výchozích hodnot nebo F10 pro uložení a odchod.

Jak vypnout Wake on LAN (WoL)

❓ „Jak vypnu Wake on LAN?"

Wake on LAN umožňuje vzdálené probuzení počítače přes síť. Pokud jej nechceš, potřebuješ ho vypnout na dvou místech: v BIOSu a ve Windows.

Krok 1 – Vypnutí v BIOSu

Advanced Mode (F7) → Advanced → APM Configuration
  • Zapni PC a zmáčkni Delete pro vstup do BIOSu.
  • Přejdi do Advanced Mode klávesou F7.
  • V horním menu vyber záložku Advanced.
  • Klikni na APM Configuration.
  • Nastav Power On By PCI-E → Disabled.
  • Volitelně: nastav ErP Ready → Enabled (zakáže i USB napájení a další WoL zdroje).
  • Ulož a odejdi: F10 → OK.
Advanced → APM Configuration
ErP ReadyDisabled
▶ Power On By PCI-EDisabled ✓
Power On By RTCDisabled
Restore AC Power LossPower Off

Krok 2 – Vypnutí ve Windows (nutné pro úplné deaktivování)

  • Klikni pravým tlačítkem na Start → Správce zařízení.
  • Rozbal Síťové adaptéry → pravý klik na Realtek Gaming 2.5GbE → Vlastnosti.
  • Záložka Upřesnit: najdi Wake on Magic Packet a nastav na Zakázáno.
  • Záložka Správa napájení: odškrtni Povolit tomuto zařízení probouzení počítače.
  • Potvrď OK.

Jak aktualizovat BIOS (EZ Flash 3)

❓ „Jak na aktualizaci BIOSu?"

ASUS TUF B550-PLUS podporuje metodu EZ Flash 3 přímo z BIOSu. Potřebuješ pouze USB flashdisk. Celý proces trvá přibližně 5–10 minut.

Příprava – stažení BIOS souboru

  • Navštiv asus.com/cz → vyhledej TUF GAMING B550-PLUS → Podpora → Ovladače a nástroje → BIOS.
  • Stáhni nejnovější BIOS verzi (soubor *.CAP, například TUF-GAMING-B550-PLUS-ASUS-3006.CAP).
  • Zkopíruj soubor *.CAP přímo do kořene USB disku (ne do složky). Disk formátuj jako FAT32.
  • USB disk zasuň do PC před zapnutím.

Aktualizace přes EZ Flash 3 v BIOSu

Advanced Mode (F7) → Tool → ASUS EZ Flash 3 Utility
  • Vstup do BIOSu (Delete), přejdi do Advanced Mode (F7).
  • V horním menu vyber záložku Tool.
  • Klikni na ASUS EZ Flash 3 Utility a potvrď Enter.
  • Vyber metodu via Storage Device(s) (z USB disku).
  • Zmáčkni Tab pro přechod do sloupce disku — vyber svůj USB disk.
  • Zmáčkni Tab znovu → přejdi do sloupce souborů — vyber soubor *.CAP.
  • Potvrď aktualizaci. Nevypínej PC ani neodpojuj USB po celou dobu!
  • PC se automaticky restartuje po dokončení. BIOS je aktualizován. ✅

⚠ Záloha před updatem: V menu Tool → ASUS User Profile ulož aktuální BIOS nastavení na USB disk. Po aktualizaci se nastavení resetuje na výchozí hodnoty — profil pak snadno obnovíš.
💡 BIOS FlashBack™: Deska také podporuje flashování bez CPU a RAM. Zasuň USB s BIOS souborem B550PLUS.CAP do označeného USB portu a drž FlashBack tlačítko na zadním panelu 3 sekundy. LED bliká = probíhá update. Vhodné pro záchranné flashování.

Proč BIOS ukazuje WiFi a Bluetooth?

❓ „Proč vidím BT a WiFi v BIOSu, když to deska nemá?"

Jedná se o záměrné chování a je to naprosto normální. Důvod je technický a výrobní:

🔍 Technické vysvětlení

ASUS vyrábí dvě varianty téměř identické desky:

Tvoje deska
TUF Gaming B550-PLUS
Bez WiFi modulu
M.2 Key-E slot: přítomen na PCB
Jiná varianta
TUF Gaming B550-PLUS WiFi
S WiFi 6 + BT 5.0 modulem
M.2 Key-E slot: obsazený WiFi kartou

Oba modely používají totožný BIOS firmware. ASUS nešije zvlášť BIOS pro každou verzi desky — sdílí jednu image, která obsahuje ovladače a nabídky pro WiFi/BT i pokud hardware není přítomen.

Fyzicky má tvá deska na PCB M.2 Key-E slot (malý konektor určený pro WiFi karty) — ale do balení nebyla WiFi karta přiložena. Pokud bys chtěl WiFi doplnit, stačí zakoupit kompatibilní M.2 WiFi modul (např. Intel AX200 nebo AX210).

ℹ Závěr: Zobrazení WiFi a BT v BIOSu ti nevadí ani nezpůsobuje problémy. Jedná se jen o neaktivní menu položky ze sdíleného BIOS kódu. Pokud chceš WiFi opravdu využívat, doplň M.2 WiFi kartu do Key-E slotu — BIOS ji okamžitě rozpozná.
