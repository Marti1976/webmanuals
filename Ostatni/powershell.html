Práce s PowerShellem ve Windows 11

Od otevření okna až po vlastní skripty a profil — praktický průvodce příkazovou řádkou, která ve Windows nahradila starý CMD.

PS C:\> Get-Commandkopírovat
01

Úvod – co je PowerShell

PowerShell je příkazová řádka a skriptovací jazyk od Microsoftu, nástupce starého CMD. Zásadní rozdíl: CMD pracuje čistě s textem, zatímco PowerShell pracuje s objekty — výstup každého příkazu je strukturovaná data s vlastnostmi, nejen řádky textu k rozsekání. Díky tomu lze výstup jednoho příkazu snadno „protáhnout" (pipe, znak |) do dalšího a dál s daty pracovat, třídit je, filtrovat nebo exportovat.

Od Windows 11 je PowerShell výchozím shellem ve Windows Terminálu — CMD zůstává jen kvůli zpětné kompatibilitě se staršími skripty. V praxi se PowerShell hodí na: automatizaci opakujících se úkolů, hromadnou správu souborů, instalaci a správu aplikací (i winget z předchozího návodu běží nad PowerShellem), správu uživatelů a služeb, nebo jednoduché plánované úlohy.

UKÁZKA — SEZNAM DOSTUPNÝCH PŘÍKAZŮ

Příkaz níže vypíše všechny dostupné příkazy (cmdlety) v aktuální relaci.

PS C:\> Get-Commandkopírovat
ℹ Příkazy v PowerShellu mají tvar Sloveso-Podstatné jméno (např. Get-Command, Set-Location) — jakmile znáte pár základních sloves (Get, Set, New, Remove, Copy...), uhodnete smysl spousty příkazů i bez učení nazpaměť.
02

Jak PowerShell otevřít

Nejrychlejší cesta: klikněte pravým tlačítkem na nabídku Start (nebo Win + X) a vyberte Terminál. Otevře se Windows Terminal s PowerShellem jako výchozí kartou. Alternativně stačí dát do vyhledávání na Start „PowerShell" nebo „Terminal".

Windows PowerShell 5.1 vs. PowerShell 7+

Ve Windows je předinstalovaná starší Windows PowerShell 5.1 (modré okno v klasickém zobrazení). Microsoft ale dál vyvíjí novější, rychlejší a multiplatformní PowerShell 7+ (open-source, spouští se příkazem pwsh), kterou je potřeba doinstalovat zvlášť — třeba přes winget z předchozího návodu.

PS C:\> winget install Microsoft.PowerShellkopírovat
💡 Pro běžné použití i skriptování v tomto návodu doporučujeme nainstalovat PowerShell 7+ — je rychlejší, má lepší chybové hlášky a aktivně se vyvíjí. Windows Terminal pak v nabídce karet nabídne obě verze zvlášť.

Spuštění jako správce

Pro úkony vyžadující administrátorská práva (např. Set-ExecutionPolicy pro celý počítač, instalace do systému) spusťte PowerShell se zvýšenými právy:

  • Pravý klik na Start → Terminál (správce), nebo
  • Najděte „PowerShell" ve vyhledávání, pravý klik na výsledek → Spustit jako správce.
⚠ Okno spuštěné jako správce má plný přístup k systému — příkazy v něm mohou nevratně změnit nastavení celého počítače, ne jen vašeho účtu. Používejte ho jen když je to nutné.
03

Pohyb v systému a práce se soubory

Dobrá zpráva pro zvyklé na CMD: příkazy jako dir nebo cd v PowerShellu dál fungují — jsou to jen aliasy (zkratky) na skutečné PowerShell cmdlety. Níže je přehled plných názvů i jejich zkratek.

Co chci udělatPlný cmdletAlias(y)
Zobrazit aktuální složkuGet-Locationpwd
Přejít do jiné složkySet-Locationcd
Vypsat obsah složkyGet-ChildItemdir, ls
Vytvořit soubor/složkuNew-Itemni
KopírovatCopy-Itemcopy, cp
Přesunout / přejmenovatMove-Item / Rename-Itemmove, ren
SmazatRemove-Itemdel, rm

V praxi:

PS C:\> Set-Location C:\Users\Jan\Dokumentykopírovat
PS C:\> Get-ChildItemkopírovat
PS C:\> New-Item -ItemType Directory -Name "NovaSlozka"kopírovat
PS C:\> New-Item -ItemType File -Name "poznamky.txt"kopírovat
PS C:\> Copy-Item .\poznamky.txt .\zaloha-poznamky.txtkopírovat
PS C:\> Remove-Item .\zaloha-poznamky.txtkopírovat

Čtení obsahu souboru a hledání v něm

PS C:\> Get-Content .\poznamky.txtkopírovat
PS C:\> Select-String -Path .\log.txt -Pattern "chyba"kopírovat
ℹ Get-Content vypíše celý obsah textového souboru (obdoba cat) · Select-String v souboru vyhledá řádky odpovídající zadanému textu — užitečné třeba při prohledávání logů.
04

Aliasy a nápověda

PowerShell má zabudovanou nápovědu ke každému příkazu. Při prvním použití je potřeba stáhnout aktuální texty nápovědy (jednorázově, jako správce):

PS C:\> Update-Helpkopírovat

Get-Help — jak příkaz použít

PS C:\> Get-Help Get-ChildItemkopírovat
PS C:\> Get-Help Get-ChildItem -Exampleskopírovat
PS C:\> Get-Help Get-ChildItem -Onlinekopírovat
ℹ -Examples zobrazí jen praktické ukázky použití (nejrychlejší cesta k pochopení) · -Online otevře aktuální dokumentaci přímo na webu Microsoftu.

Get-Command — když neznáte přesný název

Hledá mezi všemi dostupnými příkazy podle části názvu — výborné, když víte jen přibližně, co chcete udělat.

PS C:\> Get-Command *process*kopírovat
PS C:\> Get-Command *service*kopírovat

Aliasy — zkratky pro dlouhé příkazy

Zjistěte, který plný příkaz se za daným aliasem skrývá, nebo si vytvořte vlastní zkratku:

PS C:\> Get-Alias lskopírovat
PS C:\> Set-Alias gh Get-Helpkopírovat
💡 Při psaní příkazu stačí napsat jeho začátek a zmáčknout Tab — PowerShell automaticky doplní zbytek názvu (a opakovaným mačkáním prochází další možnosti).
05

Proměnné a datové typy

Proměnná v PowerShellu vždy začíná znakem $. Typ se nedeklaruje ručně — PowerShell si ho odvodí sám podle přiřazené hodnoty (tzv. dynamické typování).

PS C:\> $jmeno = "Jan"kopírovat
PS C:\> $cislo = 42kopírovat
PS C:\> $jmeno.GetType()kopírovat

Hodnotu proměnné vložíte do textu dvojitými uvozovkami (tzv. interpolace):

PS C:\> Write-Host "Ahoj $jmeno, dnes je ti $cislo let"kopírovat

Pole (array)

Seznam hodnot pod jednou proměnnou, přístup k prvku přes index od nuly:

PS C:\> $ovoce = @("jablko", "hruska", "banan")kopírovat
PS C:\> $ovoce[0]kopírovat
PS C:\> $ovoce.Countkopírovat

Hashtabulka (klíč → hodnota)

PS C:\> $osoba = @{ Jmeno = "Jan"; Mesto = "Praha" }kopírovat
PS C:\> $osoba.Mestokopírovat

Proměnné prostředí a automatické proměnné

Kromě vlastních proměnných má PowerShell i vestavěné — třeba systémové proměnné prostředí nebo informace o sobě samém:

PS C:\> $env:USERNAMEkopírovat
PS C:\> $PSVersionTablekopírovat
ℹ $env:NÁZEV čte systémové proměnné prostředí (např. $env:PATH) · $PSVersionTable ukáže, jakou verzi PowerShellu právě používáte.
06

Execution Policy

Execution Policy je bezpečnostní pojistka Windows, která řídí, jaké .ps1 skripty smí na počítači běžet. Ve výchozím nastavení Windows (Restricted) neběží žádné skripty vůbec — jen jednotlivé příkazy zadané ručně. To je důvod, proč stažený skript často „nejde spustit", dokud politiku nezměníte.

PS C:\> Get-ExecutionPolicykopírovat
ÚroveňCo povoluje
RestrictedVýchozí stav. Žádné skripty neběží, jen ruční příkazy.
RemoteSignedVlastní lokální skripty běží bez omezení, stažené z internetu musí mít digitální podpis. Doporučeno pro běžné použití.
AllSignedÚplně všechny skripty (i vlastní) musí být digitálně podepsané.
UnrestrictedBěží vše, u stažených skriptů jen upozornění. Nedoporučeno bez důvodu.

Změna politiky jen pro váš účet (nevyžaduje práva správce):

PS C:\> Set-ExecutionPolicy RemoteSigned -Scope CurrentUserkopírovat

Skript stažený z internetu nejde spustit

I při politice RemoteSigned Windows označí soubor stažený z internetu zvláštním příznakem („mark of the web"). Odstraníte ho příkazem:

PS C:\> Unblock-File .\skript.ps1kopírovat
⚠ Execution Policy je pojistka proti nechtěnému spuštění skriptu, ne tvrdá bezpečnostní hranice — jde ji záměrně obejít (např. parametrem -ExecutionPolicy Bypass). Spouštějte proto jen skripty, kterým důvěřujete.
07

Skripty .ps1

Skript je obyčejný textový soubor s příponou .ps1, který obsahuje posloupnost příkazů — vytvoříte ho v libovolném textovém editoru (Poznámkový blok, VS Code...).

Spuštění skriptu

Na rozdíl od CMD nestačí napsat jen název souboru — z bezpečnostních důvodů je nutné uvést i cestu, i když skript je v aktuální složce:

PS C:\> .\muj-skript.ps1kopírovat
ℹ Pokud skript nejde spustit, zkontrolujte Execution Policy (sekce 06 výše) — nejčastější příčina.

Jednoduchý ukázkový skript

Pozdraví uživatele podle jména zadaného při spuštění:

# pozdrav.ps1
param(
    [string]$Jmeno = "Host"
)

Write-Host "Ahoj, $Jmeno! Dnes je $(Get-Date -Format 'dd.MM.yyyy')."
kopírovat

Spuštění s parametrem:

PS C:\> .\pozdrav.ps1 -Jmeno "Petra"kopírovat

Podmínky a cyklus — rychlý přehled

# projde soubory ve složce a vypíše jen ty větší než 1 MB
foreach ($soubor in Get-ChildItem) {
    if ($soubor.Length -gt 1MB) {
        Write-Host "$($soubor.Name) je větší než 1 MB"
    }
}
kopírovat

Jednorázové spuštění bez měnění politiky natrvalo

Pro ověřený skript, který chcete pustit jednou bez trvalé změny Execution Policy:

PS C:\> powershell -ExecutionPolicy Bypass -File .\muj-skript.ps1kopírovat
08

Vlastní profil PowerShellu

Profil je skript, který se automaticky spustí při každém otevření PowerShellu — ideální místo pro vlastní zkratky, barvy nebo uvítací zprávu. Cestu k vašemu profilu (liší se podle toho, kde PowerShell běží — klasická konzole, VS Code, Windows Terminal) najdete v proměnné $PROFILE.

PS C:\> $PROFILEkopírovat
PS C:\> Test-Path $PROFILEkopírovat
ℹ Soubor profilu obvykle neexistuje, dokud si ho sami nevytvoříte — proto Test-Path vrátí False.

Vytvoření a úprava profilu

PS C:\> New-Item -Path $PROFILE -ItemType File -Forcekopírovat
PS C:\> notepad $PROFILEkopírovat
💡 -Force u New-Item vytvoří i nadřazené složky, pokud zatím neexistují.

Ukázkový obsah profilu

# Microsoft.PowerShell_profile.ps1

# vlastní zkratka pro rychlý přechod do oblíbené složky
function Projekty { Set-Location "C:\Users\Jan\Projekty" }
Set-Alias proj Projekty

# uvítací zpráva při startu
Write-Host "Vítej zpět, $env:USERNAME! Dnes je $(Get-Date -Format 'dddd dd.MM.yyyy')." -ForegroundColor Cyan
kopírovat
⚠ Profil je taky jen .ps1 skript — pokud máte Execution Policy nastavenou na Restricted (viz sekce 06), ani profil se nespustí. Potřebujete minimálně RemoteSigned.
