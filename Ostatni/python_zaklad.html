01

Instalace Pythonu Stažení, nastavení a ověření funkčnosti

KROK 01 Stažení Pythonu

Otevřete webový prohlížeč a přejděte na oficiální stránky Pythonu:

URL
https://www.python.org/downloads/

Klikněte na žluté tlačítko "Download Python 3.x.x" (nejnovější verze). Stáhne se instalační soubor ve formátu:

Soubor ke stažení
python-3.x.x-amd64.exe
KROK 02 Instalace Pythonu
⚠️
Důležité: Spusťte stažený soubor jako správce — pravé tlačítko myši na soubor → "Spustit jako správce".

Před kliknutím na "Install Now" nezapomeňte zaškrtnout obě políčka:

✅ Use admin privileges when installing py.exe
✅ Add python.exe to PATH  — tato volba je úplně dole na obrazovce instalátoru!

Poté klikněte "Install Now", počkejte na dokončení a klikněte "Close".

🔄
Restartujte počítač! Po instalaci je nutný restart celého systému — bez toho nemusí Python správně fungovat.
KROK 03 Ověření instalace

Po restartu otevřete příkazový řádek:

💡 Klávesová zkratka Win + R → napište cmd → Enter

Zadejte tyto dva příkazy a ověřte výstup:

CMD — příkazy k ověření
python --version pip --version

Pokud je vše v pořádku, uvidíte výstup podobný tomuto:

Očekávaný výstup
Python 3.12.1 pip 23.x.x from C:\...\pip (python 3.12)
02

Instalace potřebných knihoven Vše nainstalujete jednou přes pip v příkazovém řádku

PIP INSTALL Instalace všech knihoven

Otevřete příkazový řádek (Win + R → cmd → Enter) a spusťte tyto příkazy jeden po druhém:

CMD — pip instalace
pip install json5 pip install PyQt6 pip install tkinterdnd2 pip install pillow pip install deepl pip install python-dotenv

Počkejte, než se každý příkaz dokončí. Poté je prostředí připraveno.
